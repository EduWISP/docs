# Governance and contributing

## Community

EduWISP aims to be a community project, with documented decisions and transparent processes.

## Project lead

The project lead is **Michele Salerno**, founder of EduWISP (ADR-0012): final say on decisions, appoints module owners, owns the EduWISP name and logo.

## Roles

- Maintainers.
- Module owners: each module has its own repository and can be owned independently (ADR-0010).
- Technical reviewers.
- Documentation leads.
- Security and privacy leads.
- Community contributors.

## Decision process

Proposals are discussed publicly, justified and recorded. Relevant decisions are documented as Architecture Decision Records in the [decision log](../decisions.md).

## Channels

- **[Discussions](https://github.com/EduWISP/docs/discussions):** ideas, questions, open debate.
- **[Issues](https://github.com/EduWISP/docs/issues):** concrete proposals (requirements, Android checks, privacy, documentation) using the available templates.
- **Pull requests:** documentation changes and new ADRs.

See [CONTRIBUTING](https://github.com/EduWISP/.github/blob/main/CONTRIBUTING.md) and the [Code of Conduct](https://github.com/EduWISP/.github/blob/main/CODE_OF_CONDUCT.md).

## Contributions welcome now

- Requirements review.
- Android Enterprise compatibility analysis.
- School use cases.
- Privacy, legal and security review.
- Documentation improvements and translations.
