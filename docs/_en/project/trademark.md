# Trademark policy

The **EduWISP** name and logo are the project's distinctive signs, owned by the project lead (ADR-0012), and are **not** covered by the open licences (ADR-0006). The [Italian page](/docs/progetto/marchio/) is authoritative.

The goal: anyone who sees the EduWISP name must be able to trust it is really the EduWISP project — especially because it manages devices used by minors.

- **Allowed without asking:** stating that software is *based on EduWISP* (mandatory, see `NOTICE.md`); talking about the project; using the unmodified logo to link to the official project; schools stating they use the official version.
- **Requires written permission:** distributing a modified version under the EduWISP name or logo; using the name in third-party products, services or domains; merchandise.
- **Not allowed:** suggesting a modified version or third-party service is official or endorsed; uses that could harm the trust of schools, students and families; altering the logo.
- **Forks** are legitimate under the AGPL, but a fork distributed to others must use a different name and logo and state "Based on EduWISP".

Requests go to the project lead via [Discussions](https://github.com/EduWISP/docs/discussions).
