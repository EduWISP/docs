# ADR-0001: Registrare le decisioni con ADR

- **Stato:** Accettata
- **Data:** 2026-11-26

## Contesto

Il progetto è in fase di progettazione e molte scelte (modello scuola-famiglia, target Android, licenza) vanno discusse pubblicamente e devono restare tracciabili nel tempo.

## Decisione

Le decisioni progettuali rilevanti vengono registrate come ADR numerati nella cartella `docs/decisioni/` del repository `EduWISP/docs`, secondo il [modello](0000-modello.md).

## Conseguenze

- Chi arriva nel progetto può ricostruire il perché delle scelte.
- Una decisione si modifica solo con un nuovo ADR che la sostituisce.
